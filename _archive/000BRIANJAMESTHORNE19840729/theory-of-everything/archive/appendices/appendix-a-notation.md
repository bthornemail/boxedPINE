# Appendix A: Mathematical Notation Reference

## A.1 Quantum Mechanics Notation

### A.1.1 State Vectors and Operators

| Symbol | Meaning | Definition |
|--------|---------|------------|
| $\|ψ⟩$ | Quantum state vector | State in Hilbert space |
| $\|ψ⟩^*$ | Complex conjugate | $\|ψ⟩^* = ⟨ψ\|$ |
| $\|ψ⟩ ⊗ \|φ⟩$ | Tensor product | Product state |
| $\|ψ⟩ + \|φ⟩$ | Superposition | Linear combination |
| $\hat{A}$ | Operator | Hermitian operator |
| $\hat{A}^†$ | Hermitian conjugate | $\hat{A}^† = (\hat{A}^*)^T$ |
| $[\hat{A}, \hat{B}]$ | Commutator | $[\hat{A}, \hat{B}] = \hat{A}\hat{B} - \hat{B}\hat{A}$ |
| $\{\hat{A}, \hat{B}\}$ | Anti-commutator | $\{\hat{A}, \hat{B}\} = \hat{A}\hat{B} + \hat{B}\hat{A}$ |

### A.1.2 Epistemic States

| Symbol | Meaning | Definition |
|--------|---------|------------|
| $\|KK⟩$ | Known Knowns state | Measured, definite state |
| $\|KU⟩$ | Known Unknowns state | Superposition with known basis |

| $\|UU⟩$ | Unknown Unknowns state | Uncharted Hilbert space regions |
| $\|ψ_{epistemic}⟩$ | Epistemic state vector | $\|ψ_{epistemic}⟩ = α\|KK⟩ + β\|KU⟩ + γ\|UK⟩ + δ\|UU⟩$ |

### A.1.3 Field Operators

| Symbol | Meaning | Definition |

## A.8 Special Functions

### A.8.1 Bessel Functions

| Symbol | Meaning | Definition |
|--------|---------|------------|
| $J_n(x)$ | Bessel function of first kind | $J_n(x) = Σ_{k=0}^∞ (-1)^k (x/2)^{n+2k}/(k!(n+k)!)$ |
| $Y_n(x)$ | Bessel function of second kind | $Y_n(x) = (J_n(x)cos(nπ) - J_{-n}(x))/sin(nπ)$ |
| $H_n^{(1)}(x)$ | Hankel function of first kind | $H_n^{(1)}(x) = J_n(x) + iY_n(x)$ |
| $H_n^{(2)}(x)$ | Hankel function of second kind | $H_n^{(2)}(x) = J_n(x) - iY_n(x)$ |

### A.8.2 Special Integrals

| Symbol | Meaning | Definition |
|--------|---------|------------|
| $∫_0^∞ e^{-x} dx$ | Gamma function | $Γ(n) = (n-1)!$ |
| $∫_{-∞}^∞ e^{-x²} dx$ | Gaussian integral | $∫_{-∞}^∞ e^{-x²} dx = √π$ |
| $∫_0^∞ x^{n-1} e^{-x} dx$ | Gamma function integral | $Γ(n) = ∫_0^∞ x^{n-1} e^{-x} dx$ |
